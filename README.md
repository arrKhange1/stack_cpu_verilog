# Стековый процессор на Verilog

Задание по курсу **«Проектирование встраиваемых систем»**

В работе реализован однотактный стековый процессор на Verilog

## Что реализовано

Процессор поддерживает команды:

```text
PUSH
POP
ADD
JPUSH
IF
CALL
RET
```

Также реализованы:

- счетчик команд PC
- стек данных
- стек адресов возврата

## Архитектура

Для реализации стекового процессора предпочтительно использовать гарвардскую архитектуру, в которой память команд и память данных разделены

В данной реализации память команд не входит непосредственно в состав процессора. Процессор выдает текущий адрес команды через `pc_o`, а внешняя логика передает соответствующую инструкцию через `instr_i`

Также внутри процессора используются два отдельных стека: стек данных и стек адресов возврата. Стек данных используется для арифметических операций и хранения операндов (н-р, нужных для IF), а стек возвратов — для команд `CALL` и `RET`. Такое разделение упрощает работу с подпрограммами и не смешивает пользовательские данные с адресами возврата

Представление архитектуры вынесено в файл:
```text
stack_cpu_arch.jpg
```

## Глобальные переменные

Основные переменные вынесены в файл:

```text
stack_cpu_defs.vh
```

Там находятся:

- разрядность данных
- разрядность адреса
- размер стека
- коды команд

Например:

```verilog
`define DATA_WIDTH    16
`define ADDR_WIDTH    8
`define STACK_DEPTH   16
```

Это сделано, чтобы переменные процессора можно было менять в одном месте

## Интерфейс процессора

Основные сигналы:

```verilog
input  wire                    clk_i;
input  wire                    reset_i;
input  wire [`INSTR_WIDTH-1:0] instr_i;

output wire [`DATA_WIDTH-1:0]  top_o;
output wire [`ADDR_WIDTH-1:0]  pc_o;
output reg                     fault_o;
```

Где:

- `clk_i` — тактовый сигнал
- `reset_i` — сброс
- `instr_i` — текущая команда
- `top_o` — вершина стека
- `pc_o` — текущий адрес команды
- `fault_o` — ошибка

`i` означает входной сигнал (input) <br>
`o` означает выходной сигнал (output)

Внешняя логика подает процессору нужную инструкцию через `instr_i`

## Команды

### PUSH

Кладет значение в стек

```text
PUSH 10

| 10 |
```

### POP

Удаляет верхний элемент стека

```text
| 20 |
| 10 |

POP

| 10 |
```

### ADD

Складывает два верхних значения

```text
| 20 |
| 10 |

ADD

| 30 |
```

### JPUSH

Кладет адрес перехода в стек

Используется вместе с `IF`

### IF

Проверяет условие

Перед выполнением стек имеет вид:

```text
| адрес перехода   |
| условие |
```

Если `условие != 0`, то:

```text
PC = адрес
```

Иначе:

```text
PC = PC + 1
```

### CALL

Сохраняет адрес возврата:

```text
PC + 1
```

в отдельный стек возвратов и переходит на новый адрес

### RET

Берет адрес из стека возвратов и записывает его в `PC`

## Обработка ошибок

Сигнал:

```verilog
fault_o
```

устанавливается, если происходит неправильная операция, например:

- `POP` при пустом стеке
- `ADD`, когда элементов меньше двух
- `RET` при пустом стеке возвратов
- переполнение стека
